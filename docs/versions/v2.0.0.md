# Version 2.00 is here

This release gives Are You a Robot? a complete refresh.

## What's new

- A redesigned interface with a new visual style and typography.
- Smoother navigation across the game, rankings, results, and settings.
- A better game input experience with improved keyboard behavior.
- A new screen for publishing your score.
- Updated rankings and post-game screens.
- A new launch screen.
- General stability and compatibility improvements.

Version 2.00 is now available on the Play Store.
